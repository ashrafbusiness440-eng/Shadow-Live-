## ✨ Features

- 🎙️ Real-time voice chat rooms
- 👥 User authentication and profile management
- 🎁 Gift system with various effects
- 👑 VIP system with special privileges
- 🏆 PK battle system
- 🌟 Achievement system
- 🔔 Push notifications
- 🌙 Dark mode support
- 🌐 Multi-language support

## 🛠️ Technologies Used

- Flutter for cross-platform development
- Firebase for backend services
- Agora SDK for real-time voice communication
- GetIt for dependency injection
- GoRouter for navigation

## 🚀 Getting Started

1. Clone the repository
```bash
git clone https://github.com/yourusername/voice_chat_room.git
```

2. Install dependencies
```bash
flutter pub get
```

3. Set up Firebase
   - Create a new Firebase project
   - Add your `google-services.json` (Android) and `GoogleService-Info.plist` (iOS)
   - Enable Authentication, Firestore, and Storage

4. Set up Agora
   - Create an Agora account and project
   - Add your Agora App ID in the configuration

5. Run the app
```bash
flutter run
```
